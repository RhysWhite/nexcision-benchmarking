# Data

This repository does not store private real-world genomic matrices or large
generated benchmark corpora.

- Real SPANDx inputs are described in `real_inputs/README.md` and supplied
  locally only when authorised.
- Synthetic matrices are recreated from version-controlled generators and
  manifests.
- Compact measured-result tables, system metadata and derived summaries are
  retained in Git so reported claims remain auditable.
- Multi-gigabyte generated matrices, filtered outputs and repeated raw logs are
  excluded from Git history and should be archived with a tagged release or in
  a research-data repository when required.
