# Experiment 4 — biological and epidemiological impact

## Question

How does controlled genomic-region excision affect pairwise SNP distances, cluster membership and phylogenetic interpretation in real bacterial datasets?

## Candidate datasets

- hospital *Klebsiella pneumoniae* transmission surveillance;
- New Zealand MRSA AK3;
- *Escherichia coli* ST131 Clade C.

## Planned comparisons

- unfiltered matrix;
- recombination-region-filtered matrix;
- curated mobile-element/repeat-filtered matrix;
- combined filtered matrix.

## Outcomes

- sites removed;
- change in pairwise SNP distance;
- epidemiological threshold crossings;
- cluster concordance;
- tree length and topology metrics;
- whether substantive clinical or epidemiological conclusions change.
