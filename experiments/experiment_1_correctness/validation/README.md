# Experiment 1 validation

This directory contains reproducibility material for the formal correctness evaluation of NEXCISION.

## Completed stages

### 1. Genuine SPANDx input pilot

Three genuine transposed NEXUS matrices generated by SPANDx were used to establish the supported real-world input syntax:

| Dataset | SPANDx version | Taxa | Site rows | Study |
|---|---:|---:|---:|---:|
| ST131 OXA-48 | 4.0.4 | 47 | 266 | [10.1016/j.drup.2025.101327](https://doi.org/10.1016/j.drup.2025.101327) |
| ST131 Clade C | 3.2 | 237 | 4,649 | [10.1099/mgen.0.001452](https://doi.org/10.1099/mgen.0.001452) |
| MRSA AK3 | 4.0.4 | 396 | 10,481 | [10.1038/s41467-024-45608-1](https://doi.org/10.1038/s41467-024-45608-1) |

Pilot tests covered exact-site filtering, short intervals, inclusive boundaries, overlapping, reversed, unsorted, duplicate and adjacent regions, no-match intervals, and all-site removal safety.

The machine-readable summary of all six real-file sanity checks is available in [`real_file_sanity_checks.tsv`](real_file_sanity_checks.tsv).

### 2. Independent truth checker

The deliberately simple oracle in [`oracle/expected_rows.py`](oracle/expected_rows.py) calculates expected removed and retained rows without importing any NEXCISION code. It uses direct inclusive interval comparisons rather than NEXCISION's optimized interval logic.

Run every permanent case from the repository root:

```bash
python experiments/experiment_1_correctness/validation/run_fixed_cases.py
```

A successful run prints one `PASS` line per case followed by:

```text
PASS — all 17 fixed validation cases
Oracle and NEXCISION agreed on removed rows, retained rows, order,
state strings, dimensions, regional counts, and report checksums.
```

This command runs both the independent oracle and the NEXCISION command-line interface, then compares:

- removed rows;
- retained rows and their order;
- retained state strings;
- the filtered NEXUS file;
- `nchar` and `ntax` handling;
- per-region counts;
- report values and SHA-256 checksums.

GitHub Actions runs these fixed validation cases on every push and pull request.

### 4. Permanent safety validation

The [`safety_cases/`](safety_cases/) directory contains a permanent all-sites
case in which the supplied interval contains every coordinate-labelled row.

Run it from the repository root:

```bash
python experiments/experiment_1_correctness/validation/run_safety_cases.py
```

The case verifies both required behaviours:

- by default, NEXCISION exits with code `2`, reports that all rows would be
  removed, and writes no output files;
- with `--allow-empty`, NEXCISION intentionally removes all six rows, changes
  `nchar` from `6` to `0`, reports the correct regional count, and records
  valid output checksums.

GitHub Actions runs the safety validation on every push and pull request.

### 5. File-format and content preservation

Six permanent cases test the supported formatting variants directly:

- whole-line comments and blank lines inside the matrix;
- variable indentation and space-separated states;
- tab-separated states matching genuine SPANDx v4.0.4 output;
- mixed NEXUS command capitalisation and spaces around dimension assignments;
- an inline semicolon attached to a retained final row;
- removal of a final row that carries the inline matrix semicolon.

All six cases passed. In every case, the independent oracle and NEXCISION
agreed exactly, all retained row text and ordering were preserved, `ntax`
remained unchanged, and `nchar` was updated correctly. The machine-readable
summary is available in
[`format_preservation_results.tsv`](format_preservation_results.tsv).

### 6. Malformed-input and output-safety validation

Twenty-six permanent cases test clean rejection of:

- missing, duplicated, unterminated, interleaved, or unparseable matrix structures;
- empty, incomplete, non-integer, zero, negative, or non-UTF-8 region files;
- invalid coordinate regular expressions;
- missing or non-UTF-8 NEXUS inputs;
- output paths that overwrite inputs, collide, already exist, are directories,
  use a file as their parent, or are nested beneath another output.

Run the complete batch from the repository root:

```bash
python experiments/experiment_1_correctness/validation/run_invalid_cases.py
```

All 26 cases must return exit code `2`, write a clear error to standard error,
leave standard output empty, preserve every pre-existing file, and create no
unintended final, temporary, or backup files. The machine-readable results are
provided in [`malformed_input_results.tsv`](malformed_input_results.tsv).

NEXCISION now stages all requested output files before committing any of them,
which prevents predictable late-output failures from leaving an incomplete
result set.

### 7. Synthetic correctness pilot

Ten deterministic, human-readable synthetic matrices provide the first generated
validation corpus. They vary matrix shape, row order, interval count, interval
geometry, removal fraction, and state-string spacing.

Run the pilot from the repository root:

```bash
python experiments/experiment_1_correctness/validation/synthetic/run_pilot_cases.py \
  --results validation/synthetic/pilot_results.tsv \
  --summary validation/synthetic/pilot_summary.json
```

All ten cases passed. The independent oracle and NEXCISION agreed exactly on
removed and retained rows, retained order and state strings, dimensions,
per-region counts, and report checksums. Full case definitions and results are
in [`synthetic/`](synthetic/).

### 8. One-hundred-case synthetic correctness corpus

The deterministic framework was expanded to 100 cases arranged across ten
scenario families and ten matrix-size variants per family. The corpus spans
2–96 taxa, 20–500 site rows, one to four regions, ascending/descending/shuffled
row order, and removal fractions from 0% to 80%.

The built NEXCISION wheel was installed in a clean Python 3.13 environment and
tested against the independent oracle. All 100 cases passed exact row-membership,
row-order, state-preservation, dimension, per-region count, checksum, and
repeat-run determinism checks. The generator was run twice and produced the same
corpus digest.

Results are available in:

### 9. One-thousand-case formal synthetic corpus

The final deterministic corpus contains 1,000 cases: ten interval and row-order
scenario families with 100 variants each. It spans 2–256 taxa, 20–1,000 site
rows, one to four regions, and removal fractions from 0% to 80%.

All 1,000 cases passed exact comparisons against the independent oracle for
removed rows, retained rows and order, unchanged state strings, dimensions,
per-region counts, checksums, and forced repeat-run determinism. In total, the
experiment evaluated 304,000 site rows: 113,740 were correctly removed and
190,260 were correctly retained.

The generated corpus was recreated twice and produced the same SHA-256 tree
digest. Generated matrices are excluded from version control because they are
fully regenerable and occupy approximately 74 MiB.

### 10. Property-based validation

Nine general invariants were evaluated with Hypothesis across 1,800 configured
generated examples. These independently exercised exact interval membership,
retained-row order and states, dimension updates, regional counts, interval-order
invariance, idempotence, no-match identity, all-site safety, duplicate regions,
overlap-union equivalence, reversed region loading, and custom coordinate
regular expressions. A separate duplicate-coordinate regression confirmed that
regional counts are row-based rather than coordinate-set based.

All nine properties and the fixed regression passed. Results are available in:

- [`property/property_results.tsv`](property/property_results.tsv)
- [`property/property_summary.json`](property/property_summary.json)

### 11. Mutation testing

Twelve plausible faults were introduced into temporary copies of NEXCISION,
including exclusive boundaries, incorrect dimension handling, ignored or
unsorted intervals, incomplete overlap merging, extraction of the wrong integer
from a row label, retained-row reordering, loss of an inline terminator, disabled
empty-matrix safety, and incorrect regional counts.

The independent behavioural probe detected all 12 mutants, giving a mutation
score of 100%. Results are available in:

- [`mutation/mutation_results.tsv`](mutation/mutation_results.tsv)
- [`mutation/mutation_summary.json`](mutation/mutation_summary.json)
