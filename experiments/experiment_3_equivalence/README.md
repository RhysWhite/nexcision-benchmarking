# Experiment 3 — independent real-data equivalence

## Question

When supplied with externally defined exclusion intervals, does NEXCISION reproduce an independently derived retained-coordinate set and downstream SNP matrix?

## Planned evaluation

- derive intervals from an independent workflow such as Gubbins output;
- apply the same coordinate interpretation to the original alignment;
- compare retained and removed coordinate sets exactly;
- compare pairwise SNP-distance matrices;
- compare downstream phylogenies generated using identical settings.

Any discrepancy will be classified as a coordinate-convention difference, an input-site difference, a parser/conversion difference or a genuine NEXCISION error.
