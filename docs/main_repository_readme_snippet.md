# Suggested validation section for the main NEXCISION README

Add this to `github.com/RhysWhite/nexcision` once the benchmarking repository is public:

```markdown
## Validation

NEXCISION has undergone formal correctness, safety and reproducibility
validation. Experimental code, benchmark results and manuscript analyses are
maintained separately in the
[NEXCISION benchmarking repository](https://github.com/RhysWhite/nexcision-benchmarking).

Experiment 1 evaluated 1,000 deterministic synthetic matrices, 304,000
coordinate-labelled site rows, genuine SPANDx outputs, malformed inputs,
property-based invariants and deliberate implementation faults.
```
