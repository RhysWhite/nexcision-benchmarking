# Result provenance rules

Every final result should record:

- NEXCISION version and wheel SHA-256;
- Git commit of this benchmarking repository;
- Python and dependency versions;
- operating system and hardware for performance tests;
- input-data checksums;
- random or deterministic seeds;
- command-line parameters;
- output checksums.

Derived tables and figures must be generated from tracked scripts. Manual changes to result files should not be used as the source of manuscript claims.
