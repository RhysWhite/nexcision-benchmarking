# Supplementary Figure S2 legend

**Figure S2. Secondary performance and quality-control analyses.**

**A,** Median elapsed time for disjoint, adjacent, overlapping and nested sets
of 10,000 intervals applied to the same approximately 1 GiB matrix.

**B,** Runtime cost of generating the deterministic JSON provenance report for
the approximately 1 GiB matrix.

**C,** Runtime normalized to each configuration median across randomized
measured-run order. The dashed horizontal line marks a ratio of 1.0.

Bars or points represent medians of five measured executions, with
interquartile-range error bars where applicable.
