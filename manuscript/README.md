# Manuscript outputs

This directory contains polished outputs for the NEXCISION manuscript.

```text
manuscript/
├── figure_legends/ # main and supplementary figure legends
├── figures/        # publication panels in PNG and editable SVG
├── results/        # manuscript-ready Results text
├── tables/         # final or candidate manuscript tables
└── supplementary/ # supplementary methods and result notes
```

Raw generated matrices and filtered benchmark outputs do not belong here.
Compact source measurements remain under the relevant experiment directory.
Every figure and table must be reproducible from tracked analysis code and
documented source results.
